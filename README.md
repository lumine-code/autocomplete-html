# autocomplete-html

HTML element and attribute autocompletions.

## Features

- **Element completions**: suggests HTML tag names as you type.
- **Attribute completions**: suggests attribute names and values for the current element.
- **MDN descriptions**: annotates suggestions with documentation sourced from MDN.

## Installation

To install `autocomplete-html` search for it in the Install pane of the Lumine settings, or run the command `lumine --install lumine-code/autocomplete-html`.

## Services

- `autocomplete.provider`: provided to supply HTML element and attribute suggestions to autocomplete.
